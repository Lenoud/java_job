# 6. 状态图 (State Diagram)

> **用途**: 描述核心实体（用户、订单、职位）在其生命周期中的状态变迁
> **阶段**: 系统设计阶段（详细设计）

## 6.1 用户状态图

```mermaid
stateDiagram-v2
    [*] --> 未注册

    未注册 --> 正常: 注册成功<br/>(role=1, status=0)
    未注册 --> 管理员: 管理员创建<br/>(role=3)

    正常 --> 已禁用: 管理员禁用<br/>(status=1)
    已禁用 --> 正常: 管理员启用<br/>(status=0)

    正常 --> 已登录: 登录成功<br/>(生成token)
    已登录 --> 已登出: 退出登录<br/>(清除token)
    已登出 --> 已登录: 重新登录

    已登录 --> 正常: Token失效
```

## 6.2 订单状态图

```mermaid
stateDiagram-v2
    [*] --> 待支付: 创建订单<br/>(status=0)

    待支付 --> 已支付: 用户支付<br/>(status=1)
    待支付 --> 已取消: 用户/管理员取消<br/>(status=3)

    已支付 --> 已完成: 订单完成<br/>(status=2)
    已支付 --> 已取消: 管理员取消<br/>(status=3)

    已完成 --> [*]
    已取消 --> [*]
```

## 6.3 职位状态图

```mermaid
stateDiagram-v2
    [*] --> 草稿: 管理员创建<br/>(status=0)

    草稿 --> 已发布: 管理员上架<br/>(status=1)
    已发布 --> 已下架: 管理员下架<br/>(status=0)

    已发布 --> 被浏览: 用户查看<br/>(pv++)
    被浏览 --> 被收藏: 用户收藏
    被浏览 --> 被投递: 用户投递
    被浏览 --> 被评论: 用户评论

    已下架 --> 已发布: 管理员重新上架
    已发布 --> 已删除: 管理员删除
    已下架 --> 已删除: 管理员删除

    已删除 --> [*]
```

## 6.4 投递状态流转

```mermaid
stateDiagram-v2
    [*] --> 已投递: 用户投递职位<br/>POST /post/create

    已投递 --> 被查看: HR查看简历
    被查看 --> 面试邀请: 通过筛选
    被查看 --> 已拒绝: 未通过筛选

    面试邀请 --> 已录用: 面试通过
    面试邀请 --> 已拒绝: 面试未通过

    已录用 --> [*]
    已拒绝 --> [*]
```

## 状态值映射

| 实体 | 状态字段 | 值 | 含义 |
|------|----------|----|------|
| 用户 | status | 0 | 正常 |
| 用户 | status | 1 | 禁用 |
| 用户 | role | 1 | 普通用户 |
| 用户 | role | 2 | 演示账号 |
| 用户 | role | 3 | 管理员 |
| 订单 | status | 0 | 待支付 |
| 订单 | status | 1 | 已支付 |
| 订单 | status | 2 | 已完成 |
| 订单 | status | 3 | 已取消 |
| 职位 | status | 0 | 下架/草稿 |
| 职位 | status | 1 | 已发布 |
